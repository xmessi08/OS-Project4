## 3. Выводы через GIL

1. **Потоки не ускоряют математику:** Наличие GIL ограничивает параллельное выполнение байт-кода Python одним потоком, а накладные расходы на борьбу за GIL замедляют работу.
2. **Накладные расходы процессов:** Процессы обходят GIL за счет независимых интерпретаторов, но требуют ресурсов на передачу данных (IPC).
3. **Потоки ускоряют I/O:** При ожидании сетевого ответа GIL освобождается, что позволяет другим потокам отправлять запросы одновременно.
